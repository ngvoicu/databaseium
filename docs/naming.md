# Naming

## Recommendation: Nautilith

*NAW-tih-lith*, from *nautilus* and Greek *lithos*, "stone".

The chambered nautilus lives only in the newest, largest chamber of its shell. When it grows, it seals the
old chamber behind a wall and moves forward, and a thin tube, the siphuncle, keeps running through every
sealed chamber. The tool works the same way. You and your agent live in `schema.sql`. Old changes are
sealed in the ledger but still connected, so lagging environments can catch up and databases can roll
back. *-lith*: the history is set in stone.

It comes with a ready-made brand:

- **A logo:** the spiral.
- **A motto:** *Eadem mutata resurgo*, "though changed, I rise again the same." Jacob Bernoulli asked for
  it on his tombstone under the logarithmic spiral, the curve of the nautilus shell.
- **A poem:** Oliver Wendell Holmes, *The Chambered Nautilus*: "Build thee more stately mansions, O my
  soul, / As the swift seasons roll! / Leave thy low-vaulted past!"

## Finalists

For all three, a web search turned up no product, company or project using the name, and the name was free
on npm, PyPI and crates.io (checked 2026-09-25).

| Name | Meaning | Feel | Notes |
|---|---|---|---|
| **Nautilith** | nautilus + stone | poetic, visual | No web results at all. 9 letters. |
| **Uniplica** | Latin *uni-* "one" + *plica* "fold": literally "one-fold", the same idea as *simplex*, the root of "simple" | minimal, Latin | The only use found is a fossil sea-snail species, [*Eumitra uniplica*](https://en.wikipedia.org/wiki/Eumitra). It reads like *duplicate* and *replica*, which helps: one copy of the truth. People will pronounce it two ways. |
| **Schemalith** | schema + stone: the schema as a single stone | plain-spoken | No web results at all. Explains itself, but "monolith" has baggage in software. |
